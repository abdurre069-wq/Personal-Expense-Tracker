# Personal Expense Tracker 💰

A beginner-friendly Python project that helps users manage and track their daily expenses. It allows users to add expenses, view their spending records, and calculate total expenses.

## 📌 Features

- Add new expenses.
- Enter expense names and amounts.
- Automatically record the expense date.
- View all recorded expenses.
- Calculate total spending.
- Validate expense amounts to prevent invalid input.
- Save expense records in a JSON file.
- Load previously saved expenses when the program starts.

## 🛠️ Technologies Used

- **Python** – Main programming language.
- **JSON** – Stores expense records.
- **OS Module** – Checks whether the data file exists.
- **Datetime Module** – Records the current date.

## 📂 Project Structure

- `main.py` – Contains the main Python program and all functions.
- `README.md` – Provides project documentation.
- `expenses.json` – Stores expense records automatically when expenses are added.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   `python main.py`

5. Follow the menu instructions to manage your expenses.
